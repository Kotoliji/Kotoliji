# Hi, I'm Kotoliji 👋

I build practical software across AI, backend systems, and user-facing applications. I enjoy turning complex workflows into tools that are clear to use, testable, and reliable to run.

My recent work focuses on document-based AI assistants, agent workflows, and desktop tools.

## Selected projects

- **[Agentic Knowledge Pipeline](https://github.com/Kotoliji/agentic-knowledge-pipeline)** — Document question answering with a LangGraph agent, a separate gRPC retrieval service, asynchronous ingestion, citations, evaluation, and observability.
- **[Knowledge Copilot](https://github.com/Kotoliji/knowledge-copilot)** — A RAG and tool-calling API with grounded answers, multiple model providers, an offline evaluation suite, and deployment infrastructure.
- **[Sidekick](https://github.com/Kotoliji/sidekick-desk)** — A Windows desktop companion that helps plan work and follow coding-assistant sessions.
- **[Knowledge Copilot Desktop](https://github.com/Kotoliji/knowledge-copilot-desktop)** — A native C++/GTK client for asking questions about documents and managing sources.
- **[Job Application Tracker](https://github.com/Kotoliji/job-application-tracker)** — A Rails app for tracking opportunities, application channels, history, and follow-ups.
- **[Model Portfolio Site](https://github.com/Kotoliji/model-business-card-site)** — Four responsive visual directions for a portfolio website, built with HTML, CSS, and JavaScript.
